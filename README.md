# bitovi/github-actions-deploy-ollama

Deploy your own LLM (large language model) like llama3 with a web based UI to an EC2 instance.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/bitovi/github-actions-deploy-ollama](https://github.com/bitovi/github-actions-deploy-ollama).
